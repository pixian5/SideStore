# 建立个人仓库并编译 SideStore IPA

- 时间：2026-11-27 15:10
- 模型：豆包
- 版本：0.7.1（CURRENT_PROJECT_VERSION 0701）

## 一、仓库

原远端 `LiveContainer/SideStore` 对当前账号（pixian5）无推送权限（403）。
已在个人账号下新建仓库并推送：

- 仓库：https://github.com/pixian5/SideStore
- 推送分支：`LiveContainerSupport`（默认分支），含提交 `e776741`
- 远端调整：`origin` → `pixian5/SideStore`，`upstream` → `LiveContainer/SideStore`

注意：本地仓库原本是**浅克隆**（`git rev-parse --is-shallow-repository` = true），
直接推空仓库会报 `remote: fatal: did not receive expected object ...` /
`index-pack failed`。处理方式：`git fetch upstream --unshallow` 补全历史后再推送。
补历史时 `git fetch upstream '+refs/heads/*:refs/remotes/upstream/*'` 会递归子模块
（minimuxer）而长时间卡住，需要加 `-c submodule.recurse=false`，
或直接只推当前分支。

## 二、IPA 构建

构建命令（不需要证书，产出未签名包）：

```sh
xcodebuild archive -project AltStore.xcodeproj -scheme SideStore -sdk iphoneos \
  -configuration Release -archivePath build/ipa-release/SideStore.xcarchive \
  -derivedDataPath build/dd-ipa \
  CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
  AD_HOC_CODE_SIGNING_ALLOWED=YES DEVELOPMENT_TEAM=XYZ0123456
```

归档成功后手动打包（与 `make ipa` 等价）：

```sh
mkdir -p Payload && cp -R <archive>/Products/Applications/SideStore.app Payload/
ditto -c -k --sequesterRsrc --keepParent Payload SideStore.ipa
```

额外产出伪签名版本（与 `make fakesign` 等价，ldid + 各自 entitlements）：

```sh
ldid -SAltStore/Resources/ReleaseEntitlements.plist      SideStore.app/SideStore
ldid -SAltWidget/Resources/ReleaseEntitlements.plist     SideStore.app/PlugIns/AltWidgetExtension.appex/AltWidgetExtension
# SideBackup.ipa 内部二进制同样 ldid 后再回包
```

产物：

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `build/SideStore-0.7.1.ipa` | 29 MB | 完全未签名，交给 SideStore/AltStore/ESign 重签 |
| `build/SideStore-0.7.1-fake.ipa` | 29 MB | ldid 伪签名（带 Release entitlements），可被部分签名工具直接重签 |
